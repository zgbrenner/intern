Windows 10 or 11, x86-64. Installs per user — no administrator rights.

How it works

  1. Drop in documents. PDFs, Word documents, Excel workbooks, emails, scanned images, plain notes — drag them onto the window, or point Intern at a folder to watch.
  2. Intern reads them on your machine. It uses the document's real text first, and OCR only when a page has none, then runs one AI model that lives entirely on your computer. Every name it proposes comes with the exact passages from the document that support it, and a confidence.
  3. You stay in charge. Nothing on disk is renamed until you approve it. Anything Intern cannot back up with evidence from the document goes to a review list instead of being guessed at, and every rename can be undone.

Private by design

Intern does its work on your computer, start to finish. Document text, extracted pages, OCR output, and the prompts sent to the model never leave the machine — no telemetry, no cloud fallback, no remote processing.

It makes exactly two network requests, ever, and both happen only when you press a button: the one-time download of the model file, and Check for updates in Settings. Neither carries anything about your documents.

Intern still works with OneDrive and SharePoint folders — through the Microsoft sync client already on your machine, not a cloud API and not an account. Intern reads and renames files in the synced folder on your disk; the only thing moving them to the cloud is the sync client you already run.

Before you run it

The installer is not Authenticode signed, because this project has no code-signing certificate. Windows SmartScreen will call it an unrecognized app; to continue, choose More info and then Run anyway.

You should not take an unrecognized-app warning lightly — so verify the download instead of trusting it. Every published installer carries a keyless Sigstore build-provenance attestation naming the repository, workflow, and commit that produced those exact bytes: 

gh attestation verify Intern_x64-setup.exe --repo zgbrenner/intern

SHA256SUMS.txt is published beside the installer and catches a corrupted download, but it proves nothing about origin — it sits on the same page as the installer. The attestation is the part that establishes where the file came from.

First run

The first time you open it, Intern asks to download the one thing the installer deliberately leaves out: the AI model file, 1.19 GiB. The download is resumable, and the file becomes active only after its exact length and SHA-256 match the manifest built into the installer. Already have the file? Choose existing model files points Intern at it. Nothing else needs installing — PDF text extraction, OCR, and inference all ship inside the app.

Updates

Intern checks for updates from Settings → Check for updates, only when you ask. There is no background poll and no timer. An update is installed only if it is signed by this project's key; anything else is refused.

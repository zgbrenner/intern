PIPELINE

How it works

Three steps, and the last one is yours.

  1. 01Documents in

    Drag them onto the window, or point Intern at a folder to watch.

    • PDF
    • WORD
    • EXCEL
    • EMAIL
    • TEXT
    • SCANS

  2. 02Read on your machine

    The document's own text first, and OCR only when a page has none.

    One AI model does the rest, on your computer.

  3. 03You approve

    Every proposal carries the passages that support it, and a confidence.

    Nothing on disk is renamed until you say so.

  • If it can't be proved, it isn't guessed Anything Intern cannot back up with evidence from the document goes to a review list.
  • Every rename can be undone Approve one document at a time, or apply all the ready ones at once.
  • Already filed? It says so A document whose content Intern has filed before is flagged as a duplicate rather than renamed again.

PRIVACY

Private by design

Intern does its work on your computer, start to finish.

Document text, extracted pages, OCR output, and the prompts sent to the model never leave the machine.

  • NO TELEMETRY
  • NO CLOUD FALLBACK
  • NO REMOTE PROCESSING
Model file
Downloaded once, when you ask for it.
Check for updates
Only when you press the button in Settings.

Those are the only two network requests Intern makes, ever. Neither carries anything about your documents.

OneDrive and SharePoint still work.

Through the Microsoft sync client already on your machine — not a cloud API, and not an account.

PROVENANCE

Before you run it

Windows will call this an unrecognized app. Here is why, and what to do about it.

The installer is not Authenticode signed.

This project has no code-signing certificate, so SmartScreen shows “Windows protected your PC”. Choose More info, then Run anyway.

You should not take an unrecognized-app warning lightly. Verify the download instead of trusting it.

Every published installer carries a keyless Sigstore build-provenance attestation naming the repository, workflow, and commit that produced those exact bytes. 

gh attestation verify Intern_x64-setup.exe --repo zgbrenner/intern
WHAT EACH ONE ACTUALLY PROVES
SHA256SUMS.txt Attestation
Catches a corrupted download YES YES
Proves where the file came from NO YES

SHA256SUMS.txt sits on the same page as the installer, so it proves nothing about origin. The attestation is the part that does.

SETUP

First run

The installer deliberately leaves out one thing: the model.

1.19 GiB the AI model file, downloaded once on first launch
  • Resumable If the connection drops, reopen Intern and it continues where it stopped.
  • Verified before use The file becomes active only after its exact length and SHA-256 match the manifest built into the installer.
  • Already have it? Choose existing model files points Intern at a copy from another machine and skips the download.

Nothing else needs installing. PDF text extraction, OCR, and inference all ship inside the app.

UPDATES

Updates, only when you ask

Settings → Check for updates. There is no background poll and no timer.

An update is installed only if it is signed by this project's key. Anything else is refused.

How to use Intern

01

Before you start

Intern reads a document and tells you what to call it.

For each document it proposes a filename that starts with the date, describes what the document concerns, and names the parties involved.

It shows its work
Every fact in a proposed name comes with the verbatim excerpt from the document that supports it, plus a confidence.
It doesn't guess
Anything it cannot back up with the document's own text goes to a review list instead.
It stays on your machine
Reading, OCR, and the AI model all run locally. Your documents never leave the computer.
No account, no sign-in, no cloud service.

Intern never asks for a password — not even for OneDrive or SharePoint, which it reaches through folders already on your disk (see section 06).

It makes two kinds of network request, both only when you press a button: the one-time model download, and Check for updates. Neither carries anything about your documents.

WHAT YOU NEED

  • Windows 10 or 11, 64-bit (x86-64).
  • About 1.5 GB of free disk space for the app and the AI model file.
  • No administrator rights. Intern installs per user.

02

Install it

Three steps, and one warning screen that is expected.

  1. Download the installer.

    Get Intern_<version>_x64-setup.exe from the download page.

  2. Click through the SmartScreen warning.

    Windows shows “Windows protected your PC” and the words “unrecognized app”. Choose More info, then Run anyway.

  3. Let it install.

    It installs for your user only — no administrator prompt, no IT ticket.

Why that warning appears

The installer is not Authenticode signed, because this project has no code-signing certificate. Don't take an unrecognized-app warning lightly in general — verify the download rather than trust it.

Every published installer carries an attestation proving which repository, workflow, and commit produced those exact bytes. Check it with the GitHub CLI: 

gh attestation verify Intern_<version>_x64-setup.exe --repo zgbrenner/intern

SHA256SUMS.txt, published beside the installer, catches a corrupted download — but it sits on the same page as the installer, so it proves nothing about origin. The attestation is the part that does.

03

First launch

The installer deliberately leaves out one thing: the AI model file, 1.19 GiB.

The first time you open Intern, a setup screen asks to download it.

It resumes
If the connection drops, reopen Intern and the download continues where it stopped.
It is verified
The file becomes active only once its exact length and SHA-256 match the manifest built into the installer, so a broken or tampered download cannot be used.
You can bring your own
Choose existing model files points Intern at a copy from another machine and skips the download. This is also how you install on a machine with no internet at all.

Nothing else needs installing. PDF reading, OCR, and inference all ship inside the app.

04

Your first document

Start with one file you already know, so you can judge the result.

  1. Drag one PDF onto the window.

    Or use Add files. One document is enough to see the whole flow.

  2. Watch it change status.

    It goes from Waiting to Processing, then lands on Ready or Needs review.

  3. Open it and read the evidence.

    The inspector shows each fact in the proposed name — the date, the type, the parties — beside the exact words from the document that support it.

  4. Approve it.

    Only now is anything renamed on disk. Changed your mind? Undo it from Completed.

05

Everyday use

Drag files or folders onto the window, or use Add files and Add folder.

FORMATS IT READS

  • PDF
  • Word .docx
  • Excel .xlsx
  • Email .eml
  • Plain text
  • Markdown
  • PNG
  • JPEG
  • TIFF
Approving in bulk
Approve one document at a time, or use Apply all ready. Every rename can be undone from Completed.
Duplicates
A document whose content Intern has already filed is flagged as a duplicate of the filed name, rather than renamed again.
Where files land
Settings has a destination folder. Leave it empty and files are renamed in place; set it and renamed files are moved there.
Expect tens of seconds per document.

Intern runs a roughly 2-billion-parameter model on your CPU, one document at a time. Leave it working through a stack — that pace is the price of nothing leaving your machine.

06

OneDrive & SharePoint

Intern connects through the folders the Microsoft sync client already keeps on your disk.

It never talks to Microsoft's servers — no Graph API client, no OAuth token, no upload code — so it never asks you to sign in.

  1. Make the library a folder on your disk.

    Your personal OneDrive already is one. For SharePoint, open the library in the browser and click Sync — or Add shortcut to OneDrive.

  2. Point Intern at it.

    In Settings, pick that folder (or any folder inside it) as the intake folder, the destination, or both.

  3. That's it.

    Files that appear in the folder get processed; renamed files sync back to the cloud through the sync client.

Intern detects sync roots and labels your pick — “Synced with OneDrive – …”, “Synced with SharePoint – …” — so you can see what you chose.

TWO THINGS PEOPLE ASK

Some files show a cloud icon in Explorer instead of a green tick

That is Files On-Demand, and it is handled. The read Intern performs is exactly what makes OneDrive fetch the content. If the machine is offline, the document waits and is picked up once the content arrives, rather than being failed.

I have files named “conflicted copy” — will Intern rename those too?

No. Files like report (Jane's conflicted copy …), or a name suffixed with a teammate's machine, are OneDrive's conflict bookkeeping — not new documents.

Intern counts them in Settings and leaves them alone. Resolve the conflict in the folder and the surviving file is picked up.

07

Watch a folder

In Settings, enable Watch a folder and pick the intake folder.

Two rules are enforced when you save, rather than discovered while running:

  • Watching requires a destination folder.
  • The destination must be outside the intake folder. Renaming in place inside a watched folder would make every result reappear as new work, so Intern refuses that configuration up front.
Scan interval
About every 20 seconds. Scan now forces an immediate pass.
Half-copied files
A file is only picked up once its size and modified time have held still for a full interval, so a file still being copied is never read.

08

Working as a team

Several computers can watch the same synced intake folder.

They coordinate through a .intern folder inside it — small files the sync client replicates like anything else. Don't delete .intern casually; it is how machines avoid processing the same document twice.

One claim per document
First claim wins, with a time-limited lease. If a machine crashes, its work is taken over automatically once the lease lapses — about 15 minutes.
Shared work queue

By default each machine only processes documents dropped on it.

Turn on Also process documents uploaded by others to share the queue — with a two-minute courtesy delay, so the uploader's own machine gets first claim.

Who is doing what
Name your machine in Settings under This machine's name, so teammates can tell the machines apart.
What the shared folder exposes

To everyone who can see the folder: filenames, file sizes, machine names, and usernames. Never document content, text, or AI output.

09

Troubleshooting

Find the sentence that sounds like your problem.

INSTALLING AND UPDATING

Windows says “Windows protected your PC” and won't run the installer

Expected — the installer is not Authenticode signed. Click More info, then Run anyway. If in doubt, verify the download first with the attestation command in section 02.

The model download stopped partway through

Reopen Intern — the download resumes where it stopped. The file is verified against its exact length and SHA-256 before it is ever used, so a broken download cannot be used by accident.

Check for updates fails

It is the only network call Intern makes besides the model download, so check your connectivity. An update that is not signed by this project's key is refused outright — that is deliberate.

DOCUMENTS

A document went to “Needs review” — did something break?

No. It means one of the facts in the proposed name could not be matched word-for-word in the document.

The review reason names which one: the date, the document type, a party, or the description.

Fix the name yourself in the inspector and approve it, or choose Keep original.

It says “Another program is still holding this file open”

Usually the sync client, mid-upload. Intern already waited a few seconds for the lock to clear before reporting this. Retry once the sync settles.

A document failed twice and stopped trying

It is in Failed, with the reason shown. Retry it manually from there.

Everything is slow

Local CPU inference is the price of nothing leaving your machine. Tens of seconds per document is normal, and the app processes one document at a time on purpose.

FOLDERS AND SYNC

A file in my watched folder is being ignored

Work through the usual causes:

  • Is it a supported format? Is it zero bytes?
  • Is it still copying or syncing in? A file is only picked up once its size and modified time have held still for a full scan interval.
  • Is it a dot-file, or an Office lock file starting with ~$? Those are ignored on purpose.
  • Did another machine claim it? Settings shows the counts.

Then try Scan now.

The watched folder settings won't save

The destination folder must exist and must be outside the intake folder. Intern refuses the loop at save time and tells you which rule was hit.

A cloud file failed while I was offline

It is held, not abandoned. Reconnect, and it is retried automatically on a later scan once the content arrives.

GOOD TO KNOW

Where does Intern keep its own data?

In per-user app data. Your documents stay where they are. Uninstalling removes the app but leaves both your documents and Intern's data alone.

Can I use it with no internet at all?

Yes — after install and the model download, or by using Choose existing model files with a copy of the model from another machine. OneDrive folders keep working locally and sync whenever the sync client next connects.

10

Updates

Settings → Check for updates. Only when you ask.

There is no background polling and no timer. An update installs only if it is signed by this project's key; anything else is refused.

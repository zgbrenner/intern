# Intern v0.1.0-alpha.1

This testing release processes documents locally. Intern does not upload document contents or filenames to a hosted service. Network access is used only when the user explicitly downloads the optional model during setup.

The Windows installer intentionally excludes model weights. The pinned Q4 text model is 1,280,835,840 bytes (about 1.19 GiB) and is the only file setup downloads; Intern verifies its exact length and SHA-256 before use. There is no vision projector.

This alpha installer is unsigned. Windows SmartScreen may show an “unrecognized app” warning. Verify the published `SHA256SUMS.txt` digest before running it.

The release includes the per-user NSIS installer, third-party notices, complete runtime license texts, a validated SPDX SBOM set, and checksums. Uninstalling the app does not remove the user’s documents or Intern user data.
